# Contributor documentation

- [SETUP.md](SETUP.md): install and verify the development environment.
- [CONTRIBUTING.md](CONTRIBUTING.md): scope, changes, and review workflow.
- [ARCHITECTURE.md](ARCHITECTURE.md): engine boundaries, lifecycle, timing, sound, and storage.
- [CONTROLS_AND_DISPLAY.md](CONTROLS_AND_DISPLAY.md): implemented controls, settings, and monochrome presentation.
- [LAUNCHER_ART.md](LAUNCHER_ART.md): Home screen card/icon animation, artwork sources and regeneration.
- [STORAGE.md](STORAGE.md): profile format, score policy, save recovery, and errors.
- [SCOREBOARDS.md](SCOREBOARDS.md): local Daily/All-time behavior and Catalog board registration.
- [TESTING.md](TESTING.md): verification status, checks and acceptance scenarios.
- [ROADMAP.md](ROADMAP.md): implemented features, remaining work and release criteria.
- [LICENSING.md](LICENSING.md): upstream provenance, attribution, and release questions.
- [REVIEWER_INSTRUCTIONS.txt](REVIEWER_INSTRUCTIONS.txt): quick start, controls, progression and review notes included in the game ZIP.

Start with [SETUP.md](SETUP.md) to build the game and [ROADMAP.md](ROADMAP.md) to choose a contribution. [TESTING.md](TESTING.md) distinguishes completed checks from outstanding hardware acceptance.
